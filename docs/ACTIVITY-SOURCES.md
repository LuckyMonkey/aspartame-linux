# Bundled Activity Sources

This inventory records the local bundle, version, and upstream reference
declared by each shipped Activity. It is the source trail for the plain
language descriptions in the offline What's This? guide.

Where an Activity declares a Sugar Labs help URL, it is linked below. A
network connection is not required to use the local help page; links are
reference material for maintainers and future documentation updates.
