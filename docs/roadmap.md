# 🗺️ Roadmap:

> **Status:** living direction, not a promise of release dates

1. Build and boot the plain live image in an Arch environment.
2. Verify Sugar, Journal, terminal, Firefox, audio, networking, and CUPS.
3. Capture systemd boot measurements after reliability exists.
4. Add focused Aspartame packaging only where upstream packages are
   insufficient.
5. Evaluate installation, updates, rollback, and hardware polish.

## GTK4 direction:

- 🧭 Keep GTK3 healthy as a comparison reference.
- 🧱 Close the highest-value visible parity gap next.
- 🧪 Promote Activities only with workflow and lifecycle evidence.
- 🌐 Add peer-backed Neighborhood testing when a second participant is available.
- 📦 Package the development overlay only after the runtime boundary is stable.

See the [conversion tracker](sugar-modernization/CONVERSION_TRACKER.md) for
gates and the [Chirality runbook](sugar-modernization/ASPARTAME_CHIRALITY.md)
for the reasoning behind the order.
