# Upstreaming

Aspartame-specific product behavior may remain downstream, but bug fixes to
Sugar should be prepared for Sugar Labs when they are generally useful.

1. Reproduce against the pinned stable package and current upstream.
2. Reduce the change to one conceptual patch.
3. Preserve Sugar’s Activity, Frame, Journal, color, and palette semantics.
4. Add a test or exact manual reproduction.
5. Record Arch/Python/GTK versions and logs.
6. Link the relevant Sugar Labs issue or pull request.
7. Submit from a branch following Sugar Labs’ contributor workflow.

Useful repositories and contribution guidance are linked from
`docs/sugar-modernization/README.md`.
