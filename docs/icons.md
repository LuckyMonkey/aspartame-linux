# Aspartame symbolic icons

The bootstrap image includes a small, flat SVG starter set under
`/usr/share/icons/hicolor/scalable/actions/`. These monochrome symbolic
icons are intended to work with Sugar theme colors.

Initial objects are network scan, server, printer, storage, and VPN. New
icons should be simple, readable at small sizes, license-compatible, and
named by object/action rather than visual metaphor.
