Aspartame What's This?

What is this?

Use the ? control to learn what something on the screen does without opening it.

This offline guide explains the Sugar things that currently have contextual help.

Home

Home is where you choose what you want to do. Your activities and the XO are here.

Journal

Journal remembers things you have worked on. Open an item to continue where you left off.

Neighborhood

Neighborhood shows people and computers around you that Aspartame can interact with.

Group

Group shows people you have deliberately joined for shared work.

Frame

The Frame appears around the edge when you need it. It provides Sugar navigation without covering your activity.

Count

Count represents boxes in rows, stacks, and layers. Draw the boxes you can see and add layers behind them.

Total

Total is the number of boxes drawn across every layer.

Previous layer

Move toward the front of the stack and edit the nearer row.

Next layer

Move deeper into the stack and edit the next row behind it.

Current layer

This tells you which row of boxes you are editing.

New layer

Add an empty row behind the deepest row.

Copy layer

Make another layer with the same arrangement of boxes.

Activity catalog

This is the current bundled Activity collection. Exact capabilities are defined by each Activity's metadata and installed version.

Across and Down

A crossword-style puzzle using letters already on the board. Use crossing letters to solve harder words.

Appel Haken

A mathematical and visual exploration connected with the four-color theorem.

BallAndBrick

Keep a ball in play and clear bricks. Timing is central.

BlockParty

Arrange blocks to solve a spatial pattern.

Clock

Explore different ways of displaying time. This is separate from the passive Frame clock.

FotoToon

Make comics and visual stories from pictures.

Implode

Remove groups of same-colored blocks as the board collapses.

IQ

Work through reasoning and puzzle challenges.

JAMClock

Explore time-related visuals in a JAM collection Activity.

Jumble

Rearrange pieces into a word or pattern.

Log

Collect troubleshooting information for a complicated program.

Mancala

Play a counter-moving board game based on pits.

Mastermind

Use feedback from guesses to deduce a hidden arrangement.

NumberRush

Practice with quick number challenges.

PlayGo

Explore the Go board game and its changing territory.

Poll

Create a question and collect responses in a shared Activity.

Portfolio

Create a slideshow from Journal entries marked as starred.

Reversi

Play the board game where surrounded pieces are turned.

Typing Turtle

Practice hand position and typing speed.

TurtleBlocks

Direct a drawing turtle with snap-together programming blocks.

Memorize

Play or create matching games.

Maze

Find paths through increasingly difficult layouts, with collaboration where supported.

Choosing and recovering

If an Activity appears empty, it may be waiting for a new document, puzzle, board, or Journal object. Check whether you launched a new copy or resumed saved work. Use Log when a technical report is needed.
