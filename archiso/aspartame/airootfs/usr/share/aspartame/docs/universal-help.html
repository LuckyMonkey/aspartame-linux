Aspartame What's This?

What is this?

Use the ? control to learn what something on the screen does without opening it.

This offline guide explains the Sugar things that currently have contextual help.

Home

Home is where you choose what you want to do. Your activities and the XO are here.

Journal

Journal remembers things you have worked on. Open an item to continue where you left off.

Neighborhood

Neighborhood shows people and computers around you that Aspartame can interact with.

Group

Group shows people you have deliberately joined for shared work.

Frame

The Frame appears around the edge when you need it. It provides Sugar navigation without covering your activity.

Count

Count represents boxes in rows, stacks, and layers. Draw the boxes you can see and add layers behind them.

Total

Total is the number of boxes drawn across every layer.

Previous layer

Move toward the front of the stack and edit the nearer row.

Next layer

Move deeper into the stack and edit the next row behind it.

Current layer

This tells you which row of boxes you are editing.

New layer

Add an empty row behind the deepest row.

Copy layer

Make another layer with the same arrangement of boxes.

Activity catalog

Choosing and recovering

If an Activity appears empty, it may be waiting for a new document, puzzle, board, or Journal object. Check whether you launched a new copy or resumed saved work. Use Log when a technical report is needed.
